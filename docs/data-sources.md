# Hospital directory sources

Initial directory entries were checked against official sources on 17 October 2026:

- [IIT Madras Institute Hospital](https://dost.iitm.ac.in/institute-hospital) and [campus contact directory](https://dost.iitm.ac.in/mitr/).
- [Apollo Speciality Hospitals, OMR](https://www.apollohospitals.com/hospitals/apollo-speciality-hospitals-omr-chennai): address and emergency/trauma services.
- [Kauvery Hospital, Alwarpet](https://www.kauveryhospital.com/our-locations/chennai/) and [contact directory](https://www.kauveryhospital.com/contact-us/).

Distances are approximate demo planning estimates from the IIT Madras main gate. They are **not measured routes**. The UI labels them as approximate and offers a map search. Administrators should confirm contact details, services, and distances before institutional deployment.

All seeded people and requests are fictional. This project is a hackathon prototype, not an officially endorsed IIT Madras service.
